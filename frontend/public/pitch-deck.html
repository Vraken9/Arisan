Empat Pilar Arsitektur Zero-Trust

Smart contract menggantikan peran bendahara manusia dengan kode terverifikasi dan eksekusi deterministik di EVM.

Non-Custodial Multi-Vault

Dana dikunci di dalam smart contract individual untuk setiap kelompok. Tidak ada admin, pengurus, maupun developer yang dapat menyentuh atau memindahkan saldo kas secara sepihak.

Deposit Jaminan & Auto-Slash

Setiap anggota mengunci deposit jaminan (Collateral Deposit). Jika peserta mangkir melunasi iuran melewati batas waktu ronde, protokol mengizinkan eksekusi Slash untuk menyita deposit dan menutup hak peserta lain.

Commit-Reveal Cryptographic Ordering

Urutan penerima arisan ditentukan oleh seluruh anggota melalui entropy rahasia (hash commit lalu reveal). Hasil dihitung menggunakan algoritma Fisher-Yates shuffle yang verifiable dan anti-frontrunning.

Audit Transparansi Publik Permanen

Setiap interaksi dicatat sebagai event blockchain immutable di BNB Smart Chain. Anggota dan publik dapat memverifikasi status pembayaran setiap saat melalui BscScan.

Siklus Hidup Kontrak

State Machine Lima Fase Terkendali

Perpindahan status grup dikendalikan secara mutlak oleh logika smart contract tanpa intervensi manual.

PHASE 01
OPEN
Pembuatan grup dengan parameter iuran, ronde, & durasi. Peserta menyetor deposit jaminan untuk mengambil slot.
PHASE 02
COMMITTING
Grup penuh. Setiap anggota mengunggah hash commitments dari angka rahasia ke jaringan blockchain.
PHASE 03
REVEALING
Anggota mengungkap angka rahasia asli. Kontrak mencocokkan hash dan mengocok urutan secara deterministik.
PHASE 04
ACTIVE
Ronde berjalan berurutan. Peserta menyetor iuran, dana pot otomatis ditransfer ke penerima giliran ronde tersebut.
PHASE 05
COMPLETED
Semua ronde selesai secara tuntas. Deposit jaminan 100% dikembalikan kepada seluruh anggota yang taat.
Mekanisme Fail-Safe Auto-Slash: Jika seorang anggota tidak membayar iuran saat deadline ronde berakhir, siapa saja dapat memanggil fungsi slashDefaulter() untuk mengeksekusi jaminan.

Arsitektur & Kode Kontrak

Solidity Factory Pattern

Implementasi kontrak modular memisahkan Registry Management (ArisanFactory) dengan Logic Vault per grup (ArisanGroup).

ArisanFactory.sol (Deployer)

Mendeploy instance vault baru dengan biaya gas teroptimasi, melacak daftar grup publik, dan mengelompokkan grup berdasarkan alamat inisiator.

ArisanGroup.sol (Vault & State Machine)

Mengelola escrow token ERC-20, penyimpanan jaminan, verifikasi komitmen kriptografi, dan distribusi pot tanpa izin kustodian sentral.

function contribute() external nonReentrant {
    if (state != GroupState.ACTIVE) revert InvalidState();
    if (hasContributed[msg.sender][currentRound]) {
        revert AlreadyContributed();
    }

    hasContributed[msg.sender][currentRound] = true;
    roundContributions[currentRound]++;

    token.safeTransferFrom(
        msg.sender, address(this), contributionAmount
    );

    // Seluruh anggota lunas -> payout ke pemenang ronde
    if (roundContributions[currentRound] == members.length) {
        _distributeRoundPot();
    }
}
